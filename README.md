# Smaartbot-AI
SmartBot AI 🤖

SmartBot AI is a simple AI-powered chatbot developed using Python, Streamlit, and Ollama.

Features

- Interactive chatbot
- AI-generated responses
- Chat history
- New Chat option

Technologies Used

- Python
- Streamlit
- Ollama

Requirements

Install the required libraries using:

pip install -r requirements.txt

How to Run

Run the following command:

streamlit run chatbot.py

Author
